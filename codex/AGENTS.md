# Future-Proof

Before writing code for a **major product evolution** — a new product, a feature built from
scratch, a rewrite, a v2, a re-architecture, a pivot, a significant AI component — read
`~/.codex/skills/future-proof/SKILL.md` and follow it, once, at the planning step, without
asking first. Also follow it when the user asks "is this future-proof?" or "run the 10x test".
Skip it for bug fixes, small refactors, config, tests and docs. Answer in the user's language.
